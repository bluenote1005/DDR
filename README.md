# 서영이와 춤을!

`arcade_dance_neon_step.mp4` 의 화면 구성을 그대로 옮긴, **손가락으로 터치하는 모바일 펌프 게임**입니다.
수록곡 4곡, 캐릭터 포즈 12종.

캐릭터는 영상/시트 속 같은 캐릭터입니다 — `char_sheet_nologo.png` 에서 3포즈(크로마키),
영상 프레임에서 9포즈(애니메이션 전용 세그멘테이션 모델로 배경 제거)를 뽑아 썼습니다.

## 실행

정적 파일이라 서버 하나면 됩니다. (`file://` 로 직접 열면 캐릭터 PNG 로딩이 막힐 수 있습니다.)

```bash
cd C:/Users/user/orca/DDR
python -m http.server 8777
```

- PC 브라우저: <http://127.0.0.1:8777/>
- 휴대폰: 같은 Wi-Fi 에서 `http://<PC의 IP>:8777/`
  (IP 확인: `ipconfig` → IPv4 주소)

iOS/Android 모두 "홈 화면에 추가" 하면 전체화면으로 실행됩니다.

## 조작

- **터치**: 화면 아래 4개 레인(← ↓ ↑ →) 중 노트가 판정선에 닿는 순간 해당 레인을 두드립니다. 멀티터치 지원이라 동시 노트(점프)도 두 손가락으로 칠 수 있습니다.
- **키보드**: `← ↓ ↑ →` / `A S D F` / `1 2 3 4`, 일시정지 `Esc` 또는 `P`

## 캐릭터 포즈 12종

`peace · step · back · hips · armsout · cheer · march · twist · point · spin · slide · jump`

패드마다 전용 포즈 세트가 돌아가서 같은 패드를 연속으로 쳐도 다른 동작이 나옵니다.
왼쪽/오른쪽 패드는 좌우 반전까지 써서 방향감이 맞습니다.

- **←/→** step · twist · slide · spin · march (좌우 반전)
- **↑** jump · cheer · armsout
- **↓** hips · march · peace · point
- **대기 중** 2박마다 hips → peace → armsout → point 순환
- **피버** 격한 포즈 세트로 바뀌고 동작 폭도 커집니다
- **25콤보마다** 뒤돌아 도는 특별 동작
- **미스** 동작이 멈추고 휘청입니다

12장 모두 같은 캔버스에 같은 발바닥 선·같은 몸 크기로 정렬해 뒀기 때문에,
포즈가 바뀌어도 캐릭터가 위아래로 튀지 않습니다. 점프 포즈만 의도적으로 띄워져 있습니다.

## 난이도 / 옵션 (타이틀 화면)

- **난이도** — EASY / NORMAL / HARD (곡마다 노트 수는 위 표 참고)
- **노트 방향** — `↓ 모바일` (기본, 아래로 떨어짐 — 엄지 위치에 판정선) / `↑ 아케이드` (영상과 같이 위로 올라감)
- **스피드** — x0.8 ~ x1.6

### 음악을 파일 대신 합성한 이유

리듬 게임에서 제일 중요한 건 노트와 음악이 어긋나지 않는 것입니다.
오디오 파일은 기기/브라우저마다 디코딩 지연이 달라 싱크가 틀어지기 쉬워서,
`AudioContext.currentTime` 을 기준으로 **음악과 채보를 같은 마디 격자 위에서 생성**했습니다.
덕분에 4곡을 넣어도 다운로드가 0바이트이고, 어떤 기기에서도 싱크가 어긋나지 않습니다.

### 난이도 밀도 조절

BPM 이 제각각이라 같은 패턴을 쓰면 174 BPM 곡이 손가락을 넘어섭니다.
그래서 채보 생성 마지막에 **최소 노트 간격** 을 걸어 난이도별 실제 초당 노트 수를
2.0 / 3.0 / 4.5 안팎으로 맞췄습니다 (느린 곡은 절대 시간, 빠른 곡은 박자 기준).

### 캐릭터가 사라지지 않는 이유

포즈 12장을 전부 DOM 에 올려두고 `visibility` 로 보여줄 것만 켭니다.
`<img>` 하나의 `src` 를 갈아끼우면 새 이미지가 준비될 때까지 그 자리가 **빈 칸**이 되는데,
포즈가 초당 4~6회 바뀌다 보니 캐릭터가 간헐적으로 사라져 보였습니다
(측정값: 2731 샘플 중 22회). 클래스만 토글하는 지금 방식은 구조적으로 그럴 수가 없습니다.

### 파일을 고쳤는데 반영이 안 될 때

GitHub Pages 는 `Cache-Control: max-age=600` 으로 내려줍니다.
그래서 `index.html` 의 CSS/JS 링크에 `?v=숫자` 를 붙여 뒀습니다.

**CSS 나 JS 를 수정하면 반드시 이 숫자를 올려주세요.**

```html
<link rel="stylesheet" href="styles.css?v=5">
<script src="src/audio.js?v=5"></script>
```

올리지 않으면 브라우저가 예전 파일을 계속 씁니다 (개발 중에 실제로 겪은 문제입니다).

### 휴대폰 무음 모드에서도 소리가 나는 이유

iOS 는 Web Audio 를 "ambient" 오디오 세션으로 재생하는데, 이 세션은 측면 무음 스위치에 묶여 있어
무음 모드에서 게임이 조용해졌습니다. Safari 16.4+ 는 `navigator.audioSession.type = 'playback'` 로
무음 스위치를 무시하는 세션을 요청할 수 있고, 더 낮은 버전은 무음 오디오를 실제로 재생 중인
`<audio>` 요소가 있으면 세션 종류가 바뀝니다. 둘 다 넣어 뒀습니다.

하드웨어 스위치를 무시하게 만든 만큼 **앱 안에 음소거 버튼(♪)** 을 뒀습니다.
우측 상단, BPM 배지 아래에 있고 선택은 기기에 저장됩니다.

Android 는 벨소리와 미디어 볼륨이 분리돼 있어 이 문제가 없습니다. 소리가 안 나면 미디어 볼륨을 확인하세요.
